# Meus links

Uma página simples, responsiva e independente para reunir links, inspirada no formato Linktree.

## Personalizar

- Coloque a imagem de perfil na pasta do projeto com o nome `foto-raposinha.png`.
- Em `index.html`, troque os textos e os endereços dos links.
- Para adicionar outro botão, duplique um bloco `<a class="link-button">` dentro de `.link-list`.
- Em `styles.css`, ajuste cores, espaçamentos e a animação `float`.

Abra `index.html` no navegador para visualizar.
